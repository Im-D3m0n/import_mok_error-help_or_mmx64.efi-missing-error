# import_mok_error-help
To help with installing linux. Or bypassing DMA


The error should show that mmx64.efi is not found.
Find a grub.64.efi file, duplicate it and rename it to mmx64.efi, it should fix the issue. To be extra cautious, pls off secure boot. 
Go to the UEFI settings in your computer and find "security", disable secure boot.
